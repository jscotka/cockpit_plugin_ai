---
name: cockpit-build-and-package
description: Follow the target project's Cockpit package, build, development-install, and distribution conventions
---

Inspect the target repository and installed toolchain first. `cockpit.js` provides JavaScript APIs and transport; it does not inject Cockpit or PatternFly CSS. Verify that plugin HTML explicitly loads `cockpit.js` and explicitly loads or bundles CSS, without relying on shell/global CSS inheritance. Use the validated [cockpit-podman](https://github.com/cockpit-project/cockpit-podman) pattern: import `cockpit-dark-theme` and `patternfly/patternfly-6-cockpit.scss` from the JS entry, use SCSS imports `ct-card.scss`, `page.scss`, and `global-variables` where applicable, and emit package-local `dist`/CSS artifacts. For plain HTML, keep only a small esbuild/Sass build and generated CSS; do not copy Podman's React/full distribution/Makefile machinery. Ensure matching PatternFly versions and that CSS selectors match the HTML (for example, `pf-v6-*` classes require v6 selectors). Use a starter-kit-like structure only when it matches the target. Verify the package manifest and entry points, build scripts and output directory, development installation instructions, and any RPM/package metadata or generated-file rules. Do not assume `dist` is committed, add dependencies without approval, or call a generic build equivalent to RPM readiness. Follow current Cockpit in-tree imports and package conventions; do not guess import paths or link unavailable source files at runtime. Run only documented, scoped checks and report unavailable packaging tools separately from source or build failures. Before declaring UI complete, inspect generated CSS for representative HTML selectors (`pf-v6-c-page`, card, button, tabs, and form), and run the target build.

References: adjacent `../examples/pinger/`; official [packages guide](https://docs.cockpit-project.org/cockpit-guide/latest/guide/packages.html) and [starter-kit](https://github.com/cockpit-project/starter-kit). The starter-kit is a starting example; the target repository's conventions take precedence.
